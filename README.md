# Pananames QA Automation

Автоматизовані тести на Playwright + TypeScript для dev-середовища Pananames. Покривають такі сценарії:

1. `/contacts`: створення, редагування і видалення контакту, а також збереження стану чекбоксів.
2. `/register-domain`: додавання одного домену в кошик для 3 різних доменних зон, перевірка що TOTAL в кошику відповідає ціні на сторінці пошуку.
3. `/register-domain`: пошук за SLD без зазначення зони, додавання 3 вільних доменів у кошик, перевірка що TOTAL в кошику відповідає сумі їхніх цін.

## Встановлення

Встановити залежності:

```bash
npx playwright test
```

Встановити браузер Chromium, яким керує Playwright:

```bash
npx playwright install chromium
```

Скопіювати шаблон змінних середовища і заповнити URL dev-середовища та свої дані для входу:

```bash
cp .env.example .env
```

```
BASE_URL=https://mcp.pananames-dev.com
LOGIN_URL=https://mcp.pananames-dev.com/login
USER_EMAIL=your-email@example.com
USER_PASSWORD=your-password
```

У `.env.example` лежать тільки заглушки, `BASE_URL` і `LOGIN_URL` мають вказувати на реальне dev-середовище, інакше тести не запрацюють.
## Запуск тестів

```bash
npm test
```

Тести виконуються послідовно (`workers: 1`), а не паралельно. Всі тести працюють зі спільним для акаунту списком контактів і кошиком, і після кожного тесту cleanup прибирає геть усе в обох списках.

## Структура проєкту

```
fixtures/       Глобальний логін і fixture для очищення після кожного тесту
pages/          Page Object класи
tests/          Файли з тестами
utils/          Генератори тестових даних і парсинг цін
```

Кожен тест генерує власне унікальне ім'я контакту чи SLD домену, тому тести не конфліктують ні між собою, ні з наявними даними, а fixture прибирає контакти й кошик акаунту після кожного тесту незалежно від того, що саме він створив.
